# Corely

Application de bureau Windows pour gérer une micro-entreprise : contrats, factures,
agenda, tâches, boîte de réception et carte des contrats.

Ce dépôt contient uniquement les **installateurs** et les **mises à jour** de Corely.
Le code source est privé. Les données de chaque utilisateur restent sur son ordinateur :
rien n'est envoyé ici.

## Installer

1. Ouvre la page [Releases](https://github.com/Kytosmig/Corely-releases/releases/latest).
2. Télécharge `Corely-Setup-<version>.exe` et double-clique dessus.
3. Si Windows affiche « Windows a protégé votre ordinateur », clique sur
   **Informations complémentaires**, puis **Exécuter quand même**.

Corely s'installe avec une icône sur le bureau et dans le menu Démarrer.

## Mises à jour

Corely vérifie lui-même s'il existe une nouvelle version et la télécharge en arrière-plan.
Quand elle est prête, un bouton **Redémarrer** apparaît en haut de l'app.
